Commands to add eTransfer to our repo

1. Create a new folder and clone to that folder
    git clone https://github.com/jive-vlbi/etransfer.git eTransferCodebase
2. Run the makefile
    cd eTransferCodebase && make
3. Pull new changes from the eTransfer repo, then return to original directory
    cd eTransferCodebase && git pull https://github.com/jive-vlbi/etransfer.git master && cd -
